# Hyprland Keybindings

`Super` is the main modifier.

| Category | Keys | Action |
| --- | --- | --- |
| Window | `Super+Esc` | Pick a window to kill |
| Window | `Super+Q` | Close active window |
| Window | `Super+Alt+Space` | Toggle floating |
| Window | `Super+D` | Maximize |
| Window | `Super+F` | Fullscreen |
| Window | `Super+J` | Toggle split direction |
| Window | `Super+Arrow` | Focus in direction |
| Window | `Alt+Tab` | Focus next window |
| Window | `Super+Tab` | Open window switcher |
| Window | `Super+Shift+Arrow` | Move window in direction |
| Window | `Super+Shift+1/2/3` | Move window to monitor 1/2/3 |
| Window | `Super+Shift+Mouse wheel` | Move window between monitors |
| Window | `Super+Ctrl+Shift+Left/Right` | Move window to adjacent workspace |
| Window | `Super+Ctrl+Shift+Mouse wheel` | Move window between workspaces |
| Window | `Super+Ctrl+Shift+1/2/3` | Move window to workspace 1/2/3 on its monitor |
| Window | `Super+Left mouse` | Drag window |
| Window | `Super+Right mouse` | Resize window |
| Window | `Super+-/+` | Zoom out/in |
| Window | `Super+Keypad -/+` | Zoom out/in |
| Apps | `Super+Enter` | Terminal |
| Apps | `Super+E` | Yazi file manager scratchpad |
| Apps | `Super+T` | Terminal scratchpad |
| Apps | `Super+C` or `Calculator` | Calculator |
| Apps | `Super+W` | Browser |
| Apps | `Ctrl+Shift+Esc` | System monitor |
| Apps | `Super+Z` | Noctalia settings |
| Apps | `Super+X` | Control center |
| Apps | `Super` | App launcher |
| Apps | `Super+N` | Notes scratchpad |
| Apps | `Super+I` | AI scratchpad |
| Apps | `Super+/` | This keybinding list |
| Apps | `Super+.` | Emoji launcher |
| Apps | `Super+L` | Lock session |
| Apps | `Super+Alt+C` | Session menu |
| Hardware | `Volume Up/Down` | Adjust volume |
| Hardware | `Volume Mute` | Mute speakers |
| Hardware | `Mic Mute` | Mute microphone |
| Hardware | `Play/Pause` | Toggle playback |
| Hardware | `Media Next/Previous` | Change track |
| Hardware | `Brightness Up/Down` | Adjust brightness |
| Utilities | `Super+P` | Pick a screen color |
| Utilities | `Print` | Region screenshot |
| Utilities | `Super+Print` | Full-screen screenshot |
| Utilities | `Super+Shift+W` | Wallpaper panel |
| Utilities | `Super+V` | Clipboard history |
| Utilities | `Super+A` | Notifications |
| Workspace | `Super+1/2/3` | Focus monitor 1/2/3 |
| Workspace | `Super+Alt+1/2/3` | Focus absolute workspace 1/2/3 |
| Workspace | `Super+Ctrl+1/2/3` | Focus workspace 1/2/3 on current monitor |
| Workspace | `Super+Ctrl+Left/Right` | Focus adjacent workspace |
| Workspace | `Super+Ctrl+Down` | Focus next empty workspace |
| Workspace | `Super+Mouse wheel` | Cycle workspaces/monitors |
| Workspace | `Super+Ctrl+Mouse wheel` | Cycle workspaces |
| Workspace | `Super+Shift+S` | Move window to scratchpad |
| Workspace | `Super+S` | Toggle scratchpad |
